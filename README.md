# Days To Go

A playful, brutalist countdown timer. Put a clock on it.

**Site:** [daystogo.xyz](https://daystogo.xyz) · **App:** [app.daystogo.xyz](https://app.daystogo.xyz) · **Source:** [github.com/andrewkimjoseph/daystogo](https://github.com/andrewkimjoseph/daystogo)

This repo is a monorepo:

| Path | What | Live |
| --- | --- | --- |
| [`web_app/`](web_app/) | Product — TanStack Start countdown app | [app.daystogo.xyz](https://app.daystogo.xyz) |
| [`website/`](website/) | Official marketing page (same Playful Brutalist styling) | [daystogo.xyz](https://daystogo.xyz) |

## Development

App:

```sh
cd web_app
npm i
npm run dev
```

Marketing site:

```sh
cd website
npm i
npm run dev
```

Full docs: [`web_app/README.md`](web_app/README.md) · [`website/README.md`](website/README.md).
