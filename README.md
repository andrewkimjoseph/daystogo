# Days To Go

A playful, brutalist countdown timer. Live: [app.daystogo.xyz](https://app.daystogo.xyz).

This repo is a monorepo:

| Path | What |
| --- | --- |
| [`web_app/`](web_app/) | TanStack Start web app (this is what deploys to Vercel) |
| *(later)* | Flutter mobile app, alongside `web_app/` |

## Development

```sh
cd web_app
npm i
npm run dev
```

Full app docs: [`web_app/README.md`](web_app/README.md).
